# Мой крутой сайт

Это простой, но стильный одностраничный сайт на HTML/CSS. Работает на GitHub Pages!

## Как запустить
1. Залей репозиторий на GitHub.
2. Включи GitHub Pages в настройках (Settings → Pages → Source: Deploy from a branch → main).
3. Сайт будет доступен по адресу: https://твой-логин.github.io/название-репозитория

## Что внутри
- `index.html` — главная страница.
- `assets/` — папка для будущих картинок/файлов (пока пустая).

Меняй код и коммить — сайт обновится автоматически! 🚀
